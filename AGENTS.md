# Agent Rules — pi-man

pi-man is a dev-tool focused pnpm monorepo of pi extensions, prompts, skills, agents, and TUI tooling.

## Essentials

- Use `pnpm` for all workspace commands.

## Commands

```bash
pnpm build          # build all packages
pnpm typecheck      # type-check with tsgo
pnpm test           # run tests
```
